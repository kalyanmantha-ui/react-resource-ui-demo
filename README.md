# react-resource-ui demo

Live demo of [react-resource-ui](https://www.npmjs.com/package/react-resource-ui): one headless hook, three pagination behaviors. Change a single config value (`pagination.type`: `page` | `loadmore` | `infinite`) and the same table switches behavior.

```bash
npm install
npm run dev
```

Deploy: import the repo in Vercel (Vite is auto-detected), or enable GitHub Pages with source "GitHub Actions".
